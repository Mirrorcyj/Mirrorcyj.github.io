## 创建新文章

在 `_posts/` 目录下创建新的 Markdown 文件，文件名格式为：

```
YYYY-MM-DD-文章标题.md
```

例如：`2024-01-20-如何发布新文章.md`

## Front Matter 配置

每篇文章开头需要包含 Front Matter（元数据）：

```yaml
---
layout: post
title: 文章标题
date: 2024-01-20
author: 作者名
excerpt: 文章摘要（可选）
---
```

### Front Matter 字段说明

- **layout**: 必须设置为 `post`
- **title**: 文章标题
- **date**: 发布日期，格式：`YYYY-MM-DD`
- **author**: 作者名称（可选）
- **excerpt**: 文章摘要，用于首页显示（可选）

## 编写内容

在 Front Matter 之后，使用 Markdown 语法编写文章内容。

## 发布流程

1. 创建文章文件并保存
2. 使用 Git 提交更改：
   ```bash
   git add _posts/YYYY-MM-DD-文章标题.md
   git commit -m "发布新文章：文章标题"
   git push origin main
   ```
3. 推送到 GitHub 后，GitHub Actions 会自动构建并部署网站
4. 几分钟后，新文章就会出现在网站上

## Markdown 语法示例

- **粗体文本**
- *斜体文本*
- [链接文本](https://example.com)
- `代码片段`
- 列表项
- 引用文本

## 注意事项

- 文件名中的日期应该与 Front Matter 中的 date 保持一致
- 文件名和标题可以使用中文
- 文章会自动按日期排序，最新的文章显示在最前面
- 如果设置了 `excerpt`，首页会显示摘要；否则会显示文章前 30 个词
